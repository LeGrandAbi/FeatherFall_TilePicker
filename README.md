# FeatherFall_TilePicker
A random tile picker for my custom board game Feather Fall

# Commands:
- place the Graan-Holtgard tile in the middle of the map
- place the *village* tile
- place the *village* tile in the most *corner* position on the map
- place the *village* tile on any free position adjacent to a *biome* tile
- place *n* *biome* tiles
- place *n* *biome* tiles starting from the most *corner* position on the map
- place all *biome* tiles remaining
